# Northstar Supply — E-commerce Front-End Demo

A responsive portfolio storefront built with plain HTML, CSS, and JavaScript. It is designed to demonstrate front-end skills relevant to e-commerce and landing-page roles.

## Run in VS Code
1. Extract this folder.
2. Open the folder in VS Code.
3. Open `index.html` in a browser, or use the Live Server extension.
4. Test search, price sorting, Add to Bag, quantity controls, remove item, cart subtotal, and newsletter validation.

## Features
- Responsive layout for desktop, tablet and mobile
- Product cards with category labels and prices
- Product search and price sorting
- Interactive shopping bag with quantity updates and subtotal
- Newsletter form validation and user feedback
- Accessible labels, focus states, and Escape-to-close cart drawer
- No framework or build step required

## Honest project description
This is a **front-end e-commerce demo**, not a live Shopify store. It has no backend, real payment processing, inventory sync, or email delivery. Product visuals are CSS illustrations. Before presenting it, review the code and make sure you can explain the parts you claim to have built.

## Suggested interview explanation
"I built a responsive storefront demo using HTML, CSS, and JavaScript. I implemented product search, price sorting, an interactive cart with quantity updates and subtotal calculation, and a newsletter form interaction. One challenge was keeping the cart count, item quantities, and subtotal synchronized, so I used a single cart data array and re-rendered the cart UI after each update. This is a front-end demo; it is not connected to Shopify or a payment provider."

## Next Shopify learning step
Shopify themes use Liquid templates and theme files. This demo is a useful front-end foundation, but it must be adapted to Shopify's theme architecture and tested in a development store before calling it a Shopify theme.
